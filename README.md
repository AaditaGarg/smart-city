# Smart City Intelligence System

Vehicle detection, congestion estimation, and road-damage detection with a FastAPI + PostgreSQL backend,
a React dashboard, and a rule-based decision engine for repair prioritisation and signal recommendations.

> Status: **Step 1 complete (scaffold).** Results/metrics sections are filled only from real training runs in later steps.

## Prerequisites
Python 3.10-3.12, Node 18+, Docker (for PostgreSQL), VS Code. A GPU is strongly recommended for training (CPU works for small runs).

## Setup
```bash
# 1. Python env
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt    # for GPU torch, install from pytorch.org first

# 2. Config + database
cp .env.example .env               # Windows: copy .env.example .env
docker compose up -d

# 3. Verify
python scripts/verify_setup.py

# 4. Backend
uvicorn backend.app.main:app --reload --port 8000   # http://localhost:8000/docs

# 5. Frontend (new terminal)
cd frontend && npm install && npm run dev            # http://localhost:5173
```

## Layout
```
backend/app/      FastAPI (api/, core/, db/, services/)
ml/               data, preprocessing, training, evaluation, inference
decision_engine/  repair priority + signal recommendation logic
configs/          project.yaml (classes, splits, datasets)
scripts/          setup + dataset download utilities
data/             raw / interim / processed (git-ignored)
models/           trained weights   runs/  training logs
reports/          figures + tables generated by evaluation
frontend/         React (Vite) dashboard
tests/            pytest
```
